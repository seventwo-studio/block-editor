# External clipboard normalization

`WritingClipboard.normalizeForImport` is an explicit adapter for external clipboard values. It returns a normalized clipboard, `effectivePastePolicy`, and `suggestedHostBlockTypes`. Swift, Kotlin and TypeScript share this boundary. Existing strict clipboard constructors, copy and paste APIs retain their rejection behavior.

Supported rich nodes and permitted marks retain their data, including reference IDs and opaque reference payloads. Unsupported marks and unsafe active link URLs are removed while their text remains. Unsupported or disallowed whole nodes become paragraphs of recognized visible content: list items and toggle children retain their order with line breaks, and table cells use tabs. No external asset is fetched or resolved. Image/embed metadata requires explicit `allowAssetMetadata` and a permitted URL; otherwise recognized captions, alternative text and descriptions fall back to paragraph content. Schema labels are provisional and freshened during import; actual paste allocates engine identities.

Paragraphs are always available in the returned effective policy and suggested host types. Normalization never changes the current session's authoring policy, accepted document, receipt, composition hold or history. A host that forbids paragraphs must explicitly opt into the suggested policy before pasting the fallback; strict admission continues to reject it until then. Initialize an import-capable host with paragraph support rather than temporarily changing policy around a command.

Apply `result.clipboard` with `result.effectivePastePolicy` to the appropriate shared paste command. The caller still commits native composition, chooses the anchored selection, and handles failures and recovery. This adapter does not expand the selection shapes supported by that command. Unknown kinds, unsupported clipboard versions, over-depth data and existing byte/part capacities fail before normalization. Unknown extension fields are inert metadata, not additional schema children or rendered text.
