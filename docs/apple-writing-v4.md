# Apple protocol-4 writing adapter

Create `WritingEditorModel(session:)` with an explicitly created protocol-4 `WritingSession`, then present `WritingBlockEditorView(model:)`. Existing `EditorModel`, `EditorSession` and `BlockEditorView` retain their existing APIs and epochs. Hosts supply persistence, transport, assets and publication. The constructor installs the session callbacks and supports one model per session; attach host persistence/transport forwarding to `model.onChange` after initialization.

The new AppKit/UIKit controls commit native marked text through scalar-safe shared text operations before Enter, soft break, boundary Backspace, history, formatting or structural menus. The adapter holds incoming batches while composition is active and rebases the selection before applying the command. Unchanged rich atoms and reference payloads remain intact; partial references and invalid UTF-16 boundaries reject before accepted state changes. Formatting toggles the selected mark; AppKit preserves selection range and affinity through replay and focus transfer.

Rendered controls retain opaque node origins. Current permissions and view leases are checked before any commit, and deleted origins are rejected before committing another control's composition. A clean disabled control does not block another editable control. A disabled marked draft blocks author commands until it is committed or archived. Changing native editability revokes the lease before the OS can end composition. Failed view-close commits remain available in `pendingDrafts` with text, address, selection and reason; hosts can preserve these and call `removePendingDraft` explicitly. Accepted save and pending draft storage remain separate.

Block conversion and recognized Markdown prefixes call shared commands. List Enter, empty-item exit and outdent use shared list commands. Toggles, table rows/cells, block insertion, duplicate, move and delete use shared collection operations. Scalar leaf metadata uses protocol-4 `setNodeField`; it rejects identity, schema, rich-text and collection replacement, plus conversion-owned attributes, and preserves existing author undo.

This source includes direct native-control tests and a real macOS acceptance host in `tests/AcceptanceHosts/MacWritingInput.swift`. A compiled host and synthetic control callbacks do not establish real OS IME, accessibility or installed-device acceptance. Cross-block native selection, structured paste, asset-picker/storage integration, real UIKit input and all-family accessibility acceptance remain separate platform work. OS 26 family builds must be recorded against exact source and runtime identities.
