# Captured async media completion

completeAsyncBlock accepts validated scalar image/file/embed metadata at a registered captured origin. The local request records include document/epoch, monotonic generation, cancellation/failure, retained results and applied causal receipts. They are exported beside accepted history, never replicated as content. Policy, composition, recovery, superseded invocation, deleted/reused origin, changed source and document switches retain valid inert results without applying or acknowledging them. Beginning a fresh request or resubmitting a retained one is explicit. Import/reopen neither restarts provider work nor applies results. Repeated delivery adds no history and cannot implicitly redo an author Undo. Capacity is checked before local acceptance, with cancellation/failure headroom reserved; a full result store returns the data to the host without applying or acknowledging it.

The shared metadata edit carries only the checked causal source and bounded field patch. Replay checks captured and authored shape/source even when the edit is inactive. Image updates src/alt/width/height; file updates src/name/mimeType/size; generic preview updates title/description/thumbnail and preserves its URL. Optional fields support explicit null removal. IDs, types, caption/content/structure and consumer metadata cannot be replaced. Independent fields compose with peer metadata, author Undo reveals peer winners and caption/text remains intact. Concurrent deletion prevents a valid peer completion from recreating content. Completion has no focus/selection intent and forms a step distinct from initial insertion.

Generic insertion, duplication and semantic block defaults support it. Legacy file extensions remain uninterpreted; nonmatching legacy shapes require archive/read-only compatibility handling.
