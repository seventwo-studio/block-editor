Ordered rich fragments include a checked explicit plainText fallback. Copy is read-only under composition or reduced authoring policy: it adds no transaction/history, publishes no focus change and performs no provider/asset work. Hosts settle native drafts before capturing their selection.

Whole selected blocks preserve current materialized rich/reference content and consumer metadata, including hidden toggle descendants, both columns, their identities/metadata and persisted split. Captured partial text follows original surviving atoms through peer splits, retaining current marks without copying unobserved peer insertions. Overlapping ranges and subtree coverage do not duplicate content. Copy after capture uses the current whole subtree, while later source edits cannot mutate the returned payload. Stale/deleted, foreign and forged targets reject unchanged; title copy cannot mix with body selection.

The fallback walks only known visible schema fields: separate blocks/fields use newlines, table cells tabs, code retains exact whitespace and multiline import retains empty/trailing paragraphs. Unknown accepted blocks remain intact in rich data with no invented visible metadata; they are not implicitly made authorable. The modern boundary checks wrapper version/protocol, duplicate keys, numeric fidelity, schema, depth/size and fallback consistency. Separate validateForPaste checks explicit local type/mark/asset policy without stripping accepted history or the retained payload. Plain/multiline normalization and opt-in Markdown reuse existing helpers. Asset/URL metadata is inert and never resolved by copy/admission.
