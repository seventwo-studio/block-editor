# Modern shared foundation: snapshots, origins and sessions

Initial implementation for [ST-122](https://linear.app/seventwo/issue/ST-122), from the [ST-120 command contract](modern-editor-command-contract.md) and independent [ST-140 fixture contract](acceptance/modern-editor/README.md). This implements immutable snapshot admission/serialization, shared projection origins and an explicit protocol-7 session for text, appearance and author history. The checked bridge exposes the implemented command subset. Structural/compound layout commands, full focus/selection outcomes, migration activation and typed host/JNI/WASM facade acceptance remain unfinished ST-122 work.

`ModernDocument(json:)` admits the exact format-1 envelope: document identity, plain single-line title, persisted appearance and ordered blocks. Unknown admitted envelope/appearance/block/inline fields survive canonical serialization. New documents explicitly receive an empty title and sans/default/readable appearance; received documents missing required fields reject instead of silently becoming a new document. Personal outline/focus and viewport stacking are not shared metadata.

The modern validation policy adds named semantic ink/fill roles and exactly two column containers with unique sibling identities and integral split basis points from 1000 through 9000. Descendant layouts reject even through toggle children; independent layouts at valid boundaries remain possible. Child labels remain scoped to their containers, preserving existing identity rules. Existing known block/inline validation is reused, including literal code, references, nested lists, tables and media metadata. Unknown blocks remain preserved without becoming authorable.

Raw JSON admission rejects duplicate object keys, including escaped spellings, before Foundation can collapse them. Numeric metadata rejects when a Double/canonical-JSON round trip would silently round the original decimal value. Callers retain the original bytes for archive/export/retry; this type performs no storage or activation transaction. Use the explicit raw JSON initializer at this boundary rather than introducing an unchecked decoder path. Structured fields retain their already represented JSONValue values. The existing 32 MB, 10,000-root and per-block nesting bounds are retained.

The shared structural projection now has an explicit `.document(documentID:)` origin for metadata and title atoms. It has no body placement, so a consumer block with the same string ID stays distinct. Modern column containers are typed collection owners; child identities include the layout and column path, and logical order remains first column then second. The internal `ModernProjectionSeed` reuses existing scalar atom allocation and run preservation instead of creating a separate title engine. All 55 accepted snapshots retain exact admitted fields through shared projection. A primitive replay check verifies peer title insertion through author deactivation and reactivation, with body and appearance preserved; this earlier primitive check does not establish admitted protocol-7 commands or session Undo. The session layer below has its own behavior verification.

The new public `NodeID` enum case requires downstream exhaustive Swift switches to handle the document origin. Legacy authoring/admission and clipboard paths reject it; protocol 3–6 writing and protocol 2 structural receive checks verify rejected proposals do not change saved state or receipts. Consumers must still use an explicitly modern session once that session is implemented.

Legacy `Document`, protocols 3–6, bridges and existing host behavior keep their existing admission policy. Their create/restore paths still reject protocol 7. New createModern/restoreModern endpoints explicitly admit modern sessions. Legacy opaque fields called `columns` or `semanticColor` are not reinterpreted as modern schema. Archive-based cutover, structural author history, synchronized split and concurrent flattening/late-child routing still require the remaining shared implementation.

All 55 independently committed accepted ST-140 snapshots pass admission, semantic field preservation and canonical round trip, including the 5,001-block fixture. Focused tests cover malformed titles/presets/palette roles/layouts/splits, scoped identities, forbidden nesting, key/numeric preservation, limits and legacy rejection. The [implementation receipt](evidence/modern-document-foundation-2026-10-05/receipt.json) qualifies the broad regression run and final targeted checks by their source hashes. These are runtime snapshot checks; the command/concurrency/Undo and host acceptance scenarios remain pending in the existing matrix.

The [shared-origins receipt](evidence/modern-shared-origins-2026-10-05/receipt.json) records a full passing Swift regression over the new origins and shared helper extraction: 375 checks (291 core, 76 Apple adapters, 8 local-demo), including 18 modern snapshot/projection checks. Source/test hashes, unchanged independent fixture hashes and the original log identify this increment.

`ModernSession` admits an immutable modern baseline and uses protocol-7 batches/receipts, causal frontiers and atom references. Title and known body fields share scalar replay; title/literal fields reject rich atoms and title line breaks. Appearance presets are independent per-field registers, so a concurrent width edit survives font-size Undo. Operations remain validated when deactivated. Captured text ranges include their causal context, preserving direction and selecting only the captured atoms; later peer insertions are retained during replace/format. New source and independent title/appearance fixtures verify peer exchange, author Undo/Redo, saved history and new-author reopen.

Typing groups are explicit local history tokens. Hosts end them at selection/focus, paste, composition and command boundaries. One grouped Undo deactivates that author's transactions atomically while preserving peer atoms. Accepted history, held remote packets and pending recovery have separate budgets/exports; missing causal packets and schema-invalid unions leave accepted state/receipts unchanged. Held packets restore/retry through an explicit API, and release is idempotent. Repair can deactivate/reactivate only an accepted local author's history; peer history is retained. Local allowed-command policy restricts authoring without rejecting or stripping peer content.

The shared JSON bridge now exposes createModern, restoreModern, modernDocument, modernCommand, modernCapabilities and modern save/sync/position/composition/hold/recovery operations. Creation explicitly selects collaborationVersion 7. Checked command requests carry documentID/epoch, command, captured target and arguments; results distinguish applied/noop/unavailable/recoveryRequired and return the admitted transaction and anchored selection/focus when implemented. Current advertised commands are replaceText, replaceTitle, setAppearance, format, undo and redo. Raw modern requests retain duplicate-key/numeric inspection before dispatch; unknown command arguments reject. Legacy commands cannot mutate a modern handle. Unsupported column/structural commands stay unavailable, and cutoverToModern is explicitly unimplemented. The existing C ABI routes these endpoints; typed Kotlin/TypeScript integration and executed Android/WASM parity remain pending.

The native ABI runner reuses four independently committed title/appearance snapshots and exercises the compiled shared-library boundary, including creation, peer exchange, metadata Undo/Redo/reopen, checked results, malformed wire rejection and legacy admission. The existing Swift CI job now runs this same check and uploads its report. This does not replace native rendered/device acceptance or the full ST-140 command/host matrix.

The [session receipt](evidence/modern-session-2026-10-05/receipt.json) records the current full passing Swift run: 398 checks (314 core, 76 Apple adapters, 8 local-demo), including 41 modern checks. It also retains 23 focused session/bridge checks and 29 verified native C ABI responses, with source/supporting-script/input/library/log hashes. No executed Android/WASM or complete host acceptance is claimed by this evidence.

ST-121's native prototype checks stay open and gate ST-123 and downstream native input/touch work. ST-143 retains the deferred Mac automation/native check. Neither check substitutes for shared-core verification or requires holding up this independent snapshot implementation.
